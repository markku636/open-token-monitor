安裝 Token MonitorInstall Token Monitor Windows · macOS · Linux

回到用量儀表板Back to the usage dashboard

Token Monitor 統計這台電腦上 AI 工具（Claude Code、Codex、Cursor…）的用量，回報給公司的 hub。裝好打開後，它會自己連上公司的 hub，不用輸入任何設定，之後開機也會自動啟動。

Token Monitor counts how much the AI tools on this computer (Claude Code, Codex, Cursor…) are used and reports it to the company hub. Once installed and opened, it connects to the company hub by itself, with nothing to set up, and starts by itself every time you turn on the computer.

這一頁是在手機或平板上打開的。Token Monitor 要裝在你平常使用 AI 工具的電腦上，請在那台電腦打開這一頁。You opened this page on a phone or tablet. Token Monitor goes on the computer where you use AI tools: open this page on that computer.

macOS（Apple 晶片）

macOS (Apple silicon)

只支援 Apple 晶片（M1、M2、M3、M4…）的 Mac。不確定是哪一種：點螢幕左上角的蘋果圖示 →「關於這台 Mac」，「晶片」寫 Apple M… 就可以安裝；寫「處理器 Intel」的 Mac 目前不支援。

Only Macs with Apple silicon (M1, M2, M3, M4…) are supported. Not sure which one you have? Click the Apple menu in the top-left corner of the screen → "About This Mac". If "Chip" says Apple M…, you can install it. Macs that list an Intel "Processor" are not supported yet.

用終端機一步完成

Or do it in one step in Terminal

熟悉終端機的話，拖進「應用程式」之後執行下面這一行，就可以跳過步驟 4～7，直接打開。

If you're comfortable with Terminal, run this line after dragging the app into Applications to skip steps 4–7 and open it straight away.

xattr -dr com.apple.quarantine "/Applications/Token Monitor.app"

說 app「已損毀，無法打開」時，app 本身沒有壞，是下載時加上的隔離標示擋住的：在終端機執行下面這一行，再打開一次。

If macOS says the app "is damaged and can't be opened", the app itself is fine: the quarantine flag added when you downloaded it is in the way. Run this line in Terminal and open the app again.

xattr -cr "/Applications/Token Monitor.app"

Linux（x64，例如 Ubuntu）

Linux (x64, such as Ubuntu)

這裡裝的是 Token Monitor 的桌面 app（AppImage），不是 hub 伺服器。

This installs the Token Monitor desktop app (an AppImage), not the hub server.

下載 Linux AppImageDownload the Linux AppImage Token-Monitor_<版本>_amd64.AppImage Token-Monitor_<version>_amd64.AppImage
  1. 把 AppImage 放在固定的位置（例如 ~/Applications/），開機啟動記的是這個路徑。
  2. 在終端機進到那個資料夾，執行： 
    chmod +x Token-Monitor_*_amd64.AppImage
./Token-Monitor_*_amd64.AppImage
  3. 說缺少 libfuse.so.2 時：Ubuntu 22.04 執行 sudo apt install libfuse2，24.04 執行 sudo apt install libfuse2t64，再執行一次。
  1. Keep the AppImage in a fixed place (for example ~/Applications/): starting at login remembers this path.
  2. In a terminal, go to that folder and run: 
    chmod +x Token-Monitor_*_amd64.AppImage
./Token-Monitor_*_amd64.AppImage
  3. If it says libfuse.so.2 is missing: on Ubuntu 22.04 run sudo apt install libfuse2, on 24.04 run sudo apt install libfuse2t64, then run it again.

已經裝了舊版？

Already have an older version?

直接安裝新版即可，設定和資料都會保留。

Just install the new version. Your settings and data are kept.

app 會自己檢查更新：有新版時 app 裡會提示，按「下載更新」再按「重啟更新」就完成，不用再回來這裡下載。打包時沒有設定更新來源的舊版本還不會檢查，要手動裝一次新版；Mac 手動裝好新版後第一次打開會再被擋一次，照上面的步驟做即可。Mac 的 app 要放在「應用程式」裡才能在 app 裡更新，更新後打開不會再被擋。

The app checks for updates by itself: when there's a new version, the app tells you. Click "Download update", then "Restart to update", and you're done. No need to come back here to download it. Older versions built without an update source don't check yet, so install the new version by hand once. The first time you open a new version installed by hand on a Mac, macOS blocks it once more: follow the steps above. On a Mac, the app has to be in Applications to update from inside the app, and it isn't blocked after such an update.

Linux 手動換新的 AppImage 時，先刪掉舊的檔案再打開新的，開機啟動會自動改成新的檔案。在 app 裡更新則不用做任何事。

On Linux, when you replace the AppImage by hand, delete the old file before opening the new one: starting at login switches to the new file by itself. Updating from inside the app needs nothing from you.
