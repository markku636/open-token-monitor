      說明

      • 等值成本是 tokscale 依 API 牌價換算的估計（USD），不是實際帳單；使用訂閱方案的人實際支付的是月費，授權與訂閱的實際費用以帳單為準。
      • 總覽同時列出 Token 與等值成本；模型分布依等值成本。總覽以下的區塊依 Token 排序，等值成本寫在旁邊與表格裡；趨勢可以切換成等值成本。顏色給 Token 最多的 7 個，其餘合成灰色。
      • 每天的用量算給當天持有裝置的人。沒有歸屬、但 email 網域只屬於一家公司的裝置，這裡算在那家公司（不分單位），報表 API 則算「其他」，所以兩邊的數字可能略有差異。
      • 名單人數、人均與使用率依最新一次匯入的人事名單計算，看過去的期間時僅供參考。
      • 裝置可能晚一點才上傳，最近兩三天的數字之後可能還會增加。
      • 使用者比較與單一員工的用量只給管理員。

        資料庫備份

        備份是整個資料庫的 pg_dump，含所有用量、組織、姓名與 email，下載後請依公司的個資規定保管。還原由 IT 照 docs/postgres.zh-TW.md「備份與還原」手動操作，網頁上不提供還原。手動與刪除歷史資料前的備份不會自動刪除。

        刪除紀錄

        所有裝置在這個月 1 日以前的每日用量、每月用量與 session 明細都會刪除，用量分析與報表不再有那些月份；之後用戶端補傳的舊資料也不會再寫入。刪除前一定先備份，那份備份不會自動刪除，要找回資料就還原它。
